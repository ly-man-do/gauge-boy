Gauge Boy HOME, mockup v7 (night)

Clearer layout, written for Gauge Boy (no 3dsDL code, icons or text). New 3DS XL proportions: top 400x240, bottom 320x240, same scale. Icons are our own SVGs, the source for the app's icon atlas. The status bar uses the HOME Menu's own HUD textures and layout, in its dark variant; the bottom bar is System Settings' own grey bar (TopBase_D_00); the tiles and the Garage / Adapter bars are System Settings' own buttons (B_L, B_M), recolored to neutral night greys.
