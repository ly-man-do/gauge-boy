ABOUT
Gauge Boy: OBD-II Deluxe  version 0.5.0
Reads a car's OBD-II data (check engine light, trouble codes, live data, fuel trims) through a Wi-Fi ELM327 adapter.

Unofficial homebrew. Not made, endorsed or supported by Nintendo.

github.com/ly-man-do/gauge-boy

Trouble code text: Wal33D/dtc-database (MIT).

VIN models: NHTSA vPIC (US government, public domain).

Fonts and the rest: CREDITS.md.

Not for use by the driver while driving.
